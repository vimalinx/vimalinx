## About

我是 **七叶怀瑾 / Vimalinx**，一个喜欢把 AI、产品设计和个人工作流缝到一起的独立开发者。

I build AI-native tools, personal productivity systems, and small products that feel useful, sharp, and a little playful.

```txt
Focus       AI agents, learning tools, creative apps, automation
Style       fast prototypes -> usable systems -> polished experiences
Principle   ship the working thing, then make it beautiful
```

## Now

- Building personal AI tooling and agent workflows.
- Writing about learning, thinking, and software craft.
- Polishing small products until they feel alive.
