最近的主要工作是 **VimalinxOS**。希望人表达目标后，Agent 能发现可用能力、调用工具、操作应用、检查结果，并在出错后继续诊断和恢复。

这些能力由独立项目提供。总览仓库收录了 **9 个已公开的项目**，各自开发与发布。
